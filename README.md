#✈️ Airline Data Analysis Report

A visually engaging Power BI dashboard designed to analyze airline performance, pricing patterns, flight operations, and passenger travel characteristics. The report transforms airline data into clear, interactive insights that help users quickly understand key trends and compare important metrics.

This project is useful for data analysts, business stakeholders, aviation enthusiasts, and students who want to explore airline-related data through an intuitive and professionally designed dashboard.

📊 Project Overview

The Airline Data Analysis Report provides a centralized view of important airline metrics such as:

Total flights and airlines
Average Economy and Business class fares
Cities covered by the dataset
Price variations based on stops, travel class, and days remaining before departure
Airline-wise price comparisons
Flight distribution by airline
Arrival and departure time price patterns
Source and destination city comparisons
Detailed underlying flight data

The dashboard is designed to make complex airline data easier to explore through a combination of KPI cards, charts, comparison tables, and detailed data views.

✨ Key Features
📌 Executive Summary Dashboard

The main overview page provides a high-level snapshot of airline performance through key metrics and visualizations, including:

Total Flights
Average Economy Fare
Average Business Fare
Total Cities
Total Airlines

This gives users a quick understanding of the scale and overall pricing trends within the dataset.

📈 Fare Analysis by Stops and Class

Compare average flight prices across different numbers of stops and travel classes:

Economy vs. Business class comparison
One-stop and multi-stop flight analysis
Clear visualization of how stops can influence ticket pricing
🛫 Airline-Wise Flight Distribution

A donut chart displays the distribution of flights across different airlines, helping users identify which airlines account for a larger share of the available flight records.

💰 Average Price by Airline

A horizontal bar chart compares average prices across airlines, making it easy to identify:

Higher-priced airlines
More economical options
Pricing differences between carriers
📅 Price Trends by Days Left

The dashboard analyzes how ticket prices vary depending on the number of days remaining before departure. Users can compare these trends across Business and Economy classes.

This section helps reveal how pricing changes as the departure date approaches.

🔍 Detailed Price Analysis

The report also includes a deeper analytical view focused on pricing patterns.

⏰ Arrival vs. Departure Time Analysis

Compare average ticket prices across different time periods, such as:

Morning
Afternoon
Evening
Early Morning
Late Night
Night

This helps users understand whether flight timing may influence ticket prices.

🗺️ Source and Destination City Comparison

The dashboard compares average flight prices across major cities, providing insights into how location and route-related factors may affect airfare.

📋 Interactive Data Table

A detailed data section presents the underlying flight information, including fields such as:

Airline
Arrival time
Travel class
Days left before departure
Departure time
Destination city
Flight duration
Flight number
Ticket price
Source city
Number of stops

This detailed view allows users to move from high-level insights to individual records for further exploration.

🧭 Dashboard Navigation

The report uses a simple Back / Next navigation system to move between different analytical views. This keeps the dashboard organized while allowing users to explore both summary-level and detailed information.

The report also includes a Class filter, enabling users to focus on:

Business Class
Economy Class
🛠️ Requirements

To explore or modify this project, you will need:

Microsoft Power BI Desktop
Access to the dataset used to create the report

The visuals, measures, formatting, and dashboard layout are designed for use within Power BI.

🚀 How to Use
Open the Power BI report file in Microsoft Power BI Desktop.
Load or refresh the connected airline dataset if required.
Use the Class filter to focus on Business or Economy flights.
Navigate between dashboard pages using the Back and Next buttons.
Hover over or interact with charts to explore detailed values and comparisons.
Use the detailed data table to investigate individual flight records.
🎯 Purpose and Value

The goal of this project is to demonstrate how raw airline data can be transformed into a clear, interactive, and decision-friendly business intelligence report.

By bringing together operational and pricing metrics in one place, the dashboard helps users:

Understand airline pricing behavior
Compare Economy and Business class fares
Identify differences between airlines
Explore the effect of travel timing and stops
Analyze price trends based on days left before departure
Compare routes and cities more effectively
